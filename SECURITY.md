# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

- Use [private vulnerability reporting](https://github.com/mnema-xyz/talk-desktop/security/advisories/new) on this repository.
- Or write to [contact@mnema.xyz](mailto:contact@mnema.xyz).

Include the version, your platform, and steps to reproduce. You get an
acknowledgement within 7 days. Fixes ship in a patch release of the desktop app;
problems in the server or the web app belong in the
[talk repository](https://github.com/mnema-xyz/talk/security/policy).

## Scope

The desktop client's trust model (signed web bundle, pinned key, update
verification) is described in the [README](README.md) and in
[desktop-trusted-client.md](https://github.com/mnema-xyz/talk/blob/main/doc/desktop-trusted-client.md).
There has been no external security audit.
